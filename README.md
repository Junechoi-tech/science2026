# 한입의 여행 · Digestion Lab

중학교 2학년 「동물과 에너지」의 소화·흡수 과정을 음식으로 탐구하는 한국어 시뮬레이션입니다. 기본 페이지는 소화 탐험실이며, 기존 유전의 숲은 `genetics.html`로 보존했습니다(개발 중에는 `genetics-app.html`).

## 소화 탐험실 실행

Node.js 22.12 이상, 권장 버전 24. API 키·데이터베이스·별도 서비스가 필요하지 않습니다.

```sh
npm ci
npm run dev
```

검증은 `npm test`, 정적 배포 파일 생성은 `npm run build`입니다. 빌드는 `dist/`와 GitHub Pages용 루트 `index.html`, `genetics.html`, `assets/`를 갱신합니다. HTML 소스는 `app.html`과 `genetics-app.html`입니다. 생성된 HTML을 직접 편집하지 마세요. `npm run preview`로 빌드 결과를 확인할 수 있습니다.

- 찐감자·식빵·삶은 달걀·삶은 새우·삼겹살·아몬드 6종 선택
- 입, 식도, 위, 작은창자의 소화·흡수, 큰창자, 항문의 7단계 탐험
- 소화관의 곡선을 따라 프레임마다 움직이는 연속 이동(1×에서 기관 사이 약 1.8초), 일시 정지·속도 변경·초기화
- 기관별 예측 문제 7개: 오답 시 힌트·재도전, 정답 후 해설·분자 모형 공개, 음식별 탐구 진행 상태 유지
- 문제 도착 시 자동 정지(기본값), 전체 흐름을 이어 보는 설정, 기관 클릭과 키보드 이동
- 음식에 함께 포함된 녹말·단백질·지방의 분해 전후 분자 모형 비교
- 소화효소, 쓸개즙의 유화, 융털의 흡수 경로 설명
- 개념 노트와 해설이 있는 확인 문제 3개, 디벗의 가로·세로 터치 화면 지원(큰 선택지와 44px 이상 주요 조작 버튼)

첨부된 비상교육 중학교 과학 2의 194–199쪽을 참고했습니다. 교과서 파일·그림은 배포 파일에 포함하지 않았습니다. 지방의 최종 소화 산물은 교과서에 맞게 **지방산과 모노글리세리드**로 표시합니다. 지방 소화 산물의 재합성과 암죽관→림프→혈액 경로를 설명합니다.

함량 막대는 학습용 상대 표시이며 실제 식품 성분표나 정량 분석이 아닙니다. 음식의 영양소 전체, 실제 소화 시간·기관 크기·분자 수를 재현하지 않습니다. 영양소 논리는 `src/digestion.js`, UI는 `src/digestion-app.js`, 스타일은 `src/digestion.css`, 검증은 `test/digestion.test.js`에 있습니다. 상태는 새로고침 시 초기화됩니다. 기관 예측의 진행 상태는 음식별로 유지되며, 처음으로 초기화 버튼은 현재 음식의 예측 기록과 이동을 초기화합니다. 다른 음식의 예측 기록은 유지됩니다. 연속 이동은 실제 소화 속도를 재현하지 않습니다.

사용자가 제시한 참고 사이트는 이 환경의 네트워크 정책에서 접근이 거부되어 직접 확인하지 못했습니다. 첨부 교과서의 개념을 기준으로 새로 제작했습니다.

# 유전의 숲 · Gene Garden

사람의 유전 가계도를 관찰하고, 가설을 세우고, 교배 표로 검증하는 한국어 학습 시뮬레이션입니다. 연두·라벤더 색과 작은 새싹 캐릭터로 편안한 실험실을 만들었습니다.

## 실행

Node.js 22.12 이상(현재 환경: 24)을 사용합니다.

```sh
npm ci
npm run dev
```

터미널에 표시되는 개발 서버에서 앱을 엽니다. 정적 배포용 파일은 다음 명령으로 생성합니다.

```sh
npm test
npm run build
npm run preview
```

빌드 결과는 `dist/`에 생성됩니다. API 키, 데이터베이스, 외부 API가 필요하지 않습니다. 한국어 글꼴도 앱과 함께 제공됩니다. Vite와 Three.js를 사용합니다.

GitHub Pages가 main 브랜치의 루트를 직접 제공해도 실행되도록, `npm run build`는 루트의 `index.html`, `assets/`, `.nojekyll`도 갱신합니다. 이 생성물도 함께 커밋합니다. HTML 소스는 `app.html`이며 개발 서버의 `/`는 이 파일을 사용합니다. 루트의 생성된 `index.html`을 직접 편집하지 마세요. Actions 배포는 `dist/`를 사용합니다.

## 해볼 수 있는 것

- 상염색체 열성·우성, X 염색체 연관 열성 유전 상황 선택
- 부모의 유전자형과 자녀 수(2~4명) 조절, 가능한 수정 조합에서 자녀 무작위 생성
- 2세대 가계도의 인물 선택, 유전자형 공개, 부모의 대립유전자가 자녀에게 전달되는 애니메이션
- 관찰 → 유전 방식 가설 → 교배 표 검증 → 결론의 4단계 학습
- 오답 피드백, 2×2 퍼넷 사각형, 발현·보인자·미발현 확률 비교
- 회전·확대할 수 있는 실제 WebGL 3D DNA 이중나선과 염색체 모형
- 선택한 구성원의 대립유전자를 염색체 모형에서 비교
- 유전 개념 노트, 가이드, 초기화, 모바일 반응형 화면

설정은 현재 페이지에만 유지되며 새로고침하면 초기화됩니다. 첫 가계도는 설명용으로 고정된 표본이고, 조건 변경과 ‘자녀 다시 생성’은 독립적인 무작위 표본입니다. ‘전달 과정 보기’는 선택한 자녀(부모 선택 시 첫 자녀)에게 실제로 생성된 대립유전자 조합의 경로를 보여줍니다.

## 과학적 범위

이 앱은 **교육용 단일 유전자 모형**이며 진단·유전 상담 도구가 아닙니다. 단일 유전자, 완전 우성, 완전 침투도, 무작위 수정, 새 돌연변이 없음 등을 가정합니다. 열성 유전 예시는 일부 백색증 유형, X 연관 예시는 혈우병 A를 단순화했습니다. 우성 유전은 특정 질환을 지칭하지 않는 가상 형질입니다.

- 각 교배 표의 칸은 25%의 확률을 가집니다. 같은 유전자형인 칸도 각각의 수정 사건으로 유지합니다.
- 자녀의 수가 적으면 표본의 비율이 이론 확률과 다를 수 있습니다. 매 출생은 독립적입니다.
- 상염색체 모형의 성별은 형질 유전과 독립적으로 생성합니다. X 연관 모형은 XX/XY와 각 50% 출생 확률을 가정하며, 전체 자녀와 성별 내 발현 확률을 구분합니다.
- 실제 사람의 키·눈 색깔·피부색 등은 다유전자와 환경의 영향을 받습니다. 단순 우성·열성 모형으로 일반화할 수 없습니다.
- 3D 구조는 설명용이며 실제 원자 배열, 염색체 크기, 유전자 위치를 재현하지 않습니다. WebGL을 사용할 수 없으면 안내 문구를 보여줍니다.

## 검증

`npm test`는 열성·우성·X 연관 교배, 부계 X의 아들 전달 방지, 모든 허용 부모 조합의 확률 합, 독립 표본 생성을 검증합니다. 유전 계산은 `src/genetics.js`, 화면은 `src/main.js`, 3D 모형은 `src/molecule.js`에 있습니다.
